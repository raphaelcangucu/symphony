# Agent Session/Orchestrator Landing Benchmark Implementation Plan

**Goal:** Provision one isolated local Symphony project, execute the same landing-page prompt through session and orchestrator paths for Codex, Cursor and Claude, and capture focused visual/comparison evidence.

**Architecture:** A benchmark package owns the canonical prompt, local seed repository, six-cell run matrix, dedicated-instance API provisioning, parameterized Playwright flow and deterministic result collector. Runtime state lives outside the Git checkout; only the reproducible benchmark kit and documentation are committed.

**Tech Stack:** Node.js 22 built-ins, Playwright/Chromium, Symphony Phoenix API/channel UI, local Git repositories, React/TypeScript/Vite generated by the evaluated agents.
